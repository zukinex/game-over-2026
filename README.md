# Crystal Golem — Final Boss

Decentraland entry for the **GAME OVER 2026** game jam
([itch.io/jam/game-over-2026](https://itch.io/jam/game-over-2026)).
A 5-minute final boss fight, built with Decentraland SDK 7 (TypeScript).

## The game

You walk into a stone arena and face a 4.5 m **Crystal Golem**. Click it to
attack, dodge its telegraphed attacks, and kill it in under 5 minutes.

- **Click / tap the golem** to attack (10 damage per hit).
- **Ground Slam** — a red circle appears where you stand. Get out before it
  detonates (20 damage).
- **Crystal Volley** — the golem fires a spread of crystals (10 damage each).
- **Summon Shards** (final phase) — small shards chase you. Click them to
  smash: +100 score, +5 HP.
- **3 phases**: the golem gets faster and angrier as its HP drops
  (300 → 200 → 100), turning magenta in the final phase.
- **Win**: boss HP 0. **Lose**: your HP 0. Score = win bonus + time bonus +
  shard bonus. Play again from the victory / defeat screen.

## Play it

Local preview (needs Node.js 16+):

```bash
npm install
npm run start        # serves the scene, opens it in the Explorer
```

Or open the project folder in the
[Creator Hub](https://decentraland.org/download/creator-hub) and press Play.

Deploy target: a World assigned by DCL Regenesis Labs for the jam
(`worldConfiguration.name` in `scene.json`, added once the World is assigned).
**Freeze rule: no deploys to the submission World after Nov 30 2026, 23:59 UTC
— automatic disqualification.**

## Structure

- `assets/scene/main.composite` — static arena + golem (51 entities),
  generated by `tools/generate-composite.mjs` (inspector::Nodes kept in sync).
- `assets/scene/entity-names.ts` — entity names for code lookups.
- `src/index.ts` — entry point. `src/game.ts` — state machine, boss AI,
  attacks, projectiles, shards. `src/logic.ts` — pure logic (damage, phases,
  scoring; no SDK imports). `src/hud.tsx` — React-ECS HUD.
- `design/gdd.md` — short game design doc.
- `tools/` — composite generator + validators (not deployed).

## Verification

- `npm run build` — type-check + bundle (must exit 0).
- `node tools/test-logic.mjs` — pure-logic unit tests.
- `node tools/verify-composite.mjs` — composite integrity check.
